## 📌 Featured projects

### 🎓 Inglês Smart — complete school portal
A web system that replaced spreadsheets and manual processes at a language school:
classes and schedules, attendance and make-up lessons, competency-based
evaluations, finance, gamification with ranking and a content feed — plus a
student portal as a PWA.

After delivery, the project went through a **full refactoring**: the 30 models
that lived in a single app were split into **8 domain-oriented apps** using
migrations that preserve the database schema (no risk to the data), security was
hardened (secret key via environment variable, HTML sanitization against XSS,
write actions behind POST + CSRF) and every screen was redesigned.

`Django` `PostgreSQL` `PWA` `Chart.js` `CKEditor 5` `nh3`
**[→ view project](https://github.com/marcusvgcruz/ingles_smart)**

### 🚗 Carros — vehicle inventory with AI
Vehicle inventory with **reactive automation through Django Signals**: the car's
technical description is generated by **AI (Gemini)** at save time, and the stock —
with accumulated asset value — is recalculated on every change, keeping a history.

`Python` `Django` `Django Signals` `Gemini API` `Pillow`
**[→ view project](https://github.com/marcusvgcruz/carros)**

### 🎬 Flix API — movie catalog REST API
REST API with **JWT** authentication and full CRUD for actors, genres, movies and
reviews. The highlight is a **custom permission** that translates the HTTP method
into the Django model permission (`view_`, `add_`, `change_`, `delete_`) — access
control follows the data model with no repeated code — plus an **aggregated stats**
endpoint.

`Python` `Django REST Framework` `SimpleJWT` `SQLite`
**[→ view project](https://github.com/marcusvgcruz/flix_api)**
