## 📌 Projetos em destaque

### 🎓 Inglês Smart — portal escolar completo
Sistema web que substituiu planilhas e processos manuais de uma escola de idiomas: turmas e horários, presenças e reposições, avaliações por competência, financeiro, gamificação com ranking e feed de conteúdo — com portal do aluno em PWA (instalável no celular).

Depois da entrega, o projeto passou por uma **refatoração completa**: os 30 models que viviam em um único app foram separados em **8 apps por domínio** usando migrations que preservam o schema (nada de risco para os dados), a segurança foi endurecida (chave por variável de ambiente, sanitização de HTML contra XSS, ações de escrita com POST + CSRF) e todas as telas foram redesenhadas.

`Django` `PostgreSQL` `PWA` `Chart.js` `CKEditor 5` `nh3`
**[→ ver o projeto](https://github.com/marcusvgcruz/ingles_smart)**

### 🚗 Carros — inventário de veículos com IA
Plataforma de gestão de inventário de veículos com **automação reativa via Django Signals**: a cada cadastro ou exclusão, um registro de inventário é atualizado automaticamente com o total de veículos e o valor patrimonial acumulado. Integração com a **API do Gemini** gera a descrição técnica do veículo a partir de modelo, marca e ano.

`Python` `Django` `Django Signals` `Gemini API` `Pillow`
**[→ ver o projeto](https://github.com/marcusvgcruz/carros)**

### 🎬 Flix API — API REST de catálogo de filmes
API REST com autenticação **JWT** e CRUD completo de atores, gêneros, filmes e avaliações. O destaque é a **permissão customizada** que traduz o método HTTP na permissão de model do Django (`view_`, `add_`, `change_`, `delete_`) — o controle de acesso acompanha o modelo de dados sem código repetido. Inclui comando de importação de atores via CSV.

`Python` `Django REST Framework` `SimpleJWT` `SQLite`
**[→ ver o projeto](https://github.com/marcusvgcruz/flix_api)**
